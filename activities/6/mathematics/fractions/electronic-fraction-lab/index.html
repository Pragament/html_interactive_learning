Build the real exhibition model / wiring, materials & teaching notes

Start with the eight-LED bar

  1. Make eight equal spaces on a cardboard board. Mount an LED and a switch in each space.
  2. Connect eight branches in parallel across a 2 × AA (3V) battery pack. Each branch has its own switch, 220Ω resistor and LED in series.
  3. Connect the LED anode (long leg) towards + and cathode (short leg / flat side) towards −. Turn power off before changing wires.
  4. Label each switch 1–8. Count the lit LEDs as the numerator; all eight positions form the denominator.
+3V ─┬─ switch ─ 220Ω ─ LED ▷| ─┬─ − ├─ switch ─ 220Ω ─ LED ▷| ─┤ └─ repeat for 8 branches ──┘

Use one resistor per LED. Never connect an LED directly across the battery. Use red, amber or low-forward-voltage green LEDs for a 3V kit; some blue and white LEDs may not light reliably. Avoid shorting the battery rails.

Matching & quiz boards

For each question, use an isolated answer bank. Wire only its correct answer contact to the question contact behind the board. Two probes complete a battery–resistor–LED continuity loop. A wrong contact leaves it open. Avoid joining repeated equivalent-value groups if you need only specific pairs to work.

For green/correct and red/incorrect feedback without code, use a separate fixed question card with a correct-answer bus and an incorrect-answer bus, each feeding its own resistor + LED branch through answer switches. The simulator checks the math in software; the physical model uses prewired answers.

Progress through the classes

Classes 3–4: count equal parts and make a whole. Class 5: simplify and match fractions. Classes 6–7: add, compare and explain common denominators. The comparison symbol here is a visual math aid; two ordinary LED bars do not automatically calculate it.

Materials for this four-row adaptation

16 red 5mm LEDs (4 per row), 4 normally-open push buttons, foam board, A4 template, paper glue, 10mm copper tape, jumper wire, 2 × AA battery pack and 10 × 220Ω resistors for the 10 connected LED branches. Six remaining LEDs are unconnected visual placeholders.

Source and adaptation: The module lists a 9V battery and 220–470Ω resistance. This simulator retains the fixed LED patterns but uses the existing kit’s 3V supply and one 220Ω resistor per connected LED branch. Do not swap to 9V using this adapted wiring; a teacher must review the original circuit and current limits first.

Use a cutting mat, ruler, marker and compass for the board. An adult should supervise cutting and any soldering, using an iron stand and fume extraction. A breadboard version lets students practise before soldering. Disconnect the battery before construction or repairs.

Explain it · assessment discussion

How does pressing a button represent a fraction?

It closes the row’s circuit. The connected LEDs light while the button is held. Lit LEDs are the numerator; all four equal positions are the denominator.

Why do different buttons light different numbers?

The wiring is fixed: only 1, 2, 3 or 4 LED branches are connected in each row. The button switches a prewired group; it does not calculate a fraction.

Why is the half row 2/4, and not 2/16?

Each row is its own whole. Two of that row’s four positions are lit. The board’s 16 physical LEDs belong to four separate representations.

Where do we use this idea in electronics?

A switch completing a circuit operates indicator lamps. Several lights can show levels or progress, just as this board shows how much of a whole is represented.

How could we show 1/8 or 2/3?

Use eight equal positions with one connected LED for 1/8. Use three equal positions with two connected LEDs for 2/3. The denominator must describe that row’s whole.

Extend the learning

Compare 1/2 = 2/4 = 4/8 using the LED bar; test 1/4 + 3/8 in Addition. In a teacher-led build, compare suitable resistor values to observe brightness changes while keeping the fraction unchanged. The optional microcontroller extension in the source is outside this kit’s no-programming design.
