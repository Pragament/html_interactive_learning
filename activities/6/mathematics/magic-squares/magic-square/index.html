3×3 Magic Square

Class VI · Mathematics · Magic Constant = 15

Instructions: Place each number from 1 to 9 exactly once into the grid so that every row, every column, and both diagonals add up to the same number: 15.

Why is the magic constant 15?
The numbers 1 to 9 add up to 45 in total (1+2+3+...+9 = 45). A 3×3 magic square has 3 rows, and each row must have the same sum. Since the 3 rows together use every number exactly once, each row's sum must be 45 ÷ 3 = 15. The same logic applies to the columns and diagonals.
