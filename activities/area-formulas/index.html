Parallelogram Area =
base × height

A parallelogram can be cut and rearranged into a rectangle. The rectangle has the same base and height — so the area is the same!

Triangle Area =
½ × base × height

Two identical triangles form a parallelogram. So the triangle's area is exactly half of base × height!

Trapezium Area =
½ × (a + b) × height

Two identical trapeziums form a parallelogram with base = (a + b). So the trapezium's area is half of (a + b) × height!
