Current and Potential Difference: Series vs Parallel

Learning objective: find out that in a series circuit the current is the same everywhere while the voltage splits across resistors, and in a parallel circuit the voltage is the same across every branch while the current splits.

For teachers — discussion prompts and notes

Running it in class (about 15 minutes)

  • Project the Series tab. Ask students to predict a current reading before you tap each probe.
  • Move to Parallel and ask why the voltage probes all read the same value while the current probes differ.
  • Use Compare as the closing discussion — it is the practical reason household wiring is parallel.
  • Predict works well as an individual or paired check before the class discussion.

Discussion prompts

  • In the series circuit, why does every ammeter probe read the same value no matter where it is placed?
  • In the parallel circuit, why does the branch with the smaller resistance carry more current?
  • If one bulb fails in a series string of decorative lights, the rest go out — but not in a parallel string. Why?
  • For the same components, which configuration draws more total current from the battery, and why does that matter for the battery's lifetime?

Common misconceptions to watch for

  • Assuming current "runs out" as it passes through a resistor — in series it is unchanged everywhere.
  • Assuming voltage is the same everywhere in every circuit — it only holds across parallel branches, not along a series wire.
  • Confusing where an ammeter belongs (in the current path) with where a voltmeter belongs (across a component).

Notes on the model

  • Resistor sliders are limited to 1–100 Ω and voltage to 0–12 V so currents stay in a realistic, readable range.
  • The Compare tab always uses the same R₁, R₂ and voltage as the Series and Parallel tabs, so the comparison is fair.
