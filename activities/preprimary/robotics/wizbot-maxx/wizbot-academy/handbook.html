Concept 1: Sequence The Chef's Recipe

THE GOLDEN RULE
Everyday Life: If you bake a cake, you cannot put frosting on the cake before you bake it! You must mix → bake → cool → frost.

Robots have no imagination – they are exact machines. They read blocks strictly from top to bottom, one single block at a time. If block 2 comes before block 1, the robot will do them in that exact backwards order.

Concept 2: Events The Starter Whistle

YELLOW / ORANGE BLOCKS
Everyday Life: Runners at a race stand frozen at the starting line. They do not run until the referee blows the whistle.

Blocks cannot start themselves. An Event is the trigger that tells Wizbot: "Wake up and start reading!"

when clicked Tells Wizbot to start as soon as the green flag button is tapped in PictoBlox.

Concept 3: Loops The Energy Saver

REPEAT VS. FOREVER
Everyday Life: If your teacher says "Jump 5 times," you don't say "Jump, jump, jump, jump, jump." You count inside your head while jumping!
Loop BlockWhat Wizbot DoesReal-World Analogy
repeat (10) times Runs the blocks inside 10 times, then stops and moves on. Bouncing a basketball 10 times during practice.
forever Never stops! Keeps doing the blocks inside until battery off. A ceiling fan that spins non-stop until switched off.

Concept 4: Variables Wizbot's Memory Box

ORANGE BLOCKS
Everyday Life: Imagine a cardboard box labeled "Score". When you score a goal, you erase the paper inside and write a new number.

A Variable is a labeled box in computer memory that holds one number at a time:

set counter to 1
Puts the number 1 inside the box to start fresh.
change counter by 1
Adds +1 to whatever is already inside (1 becomes 2, then 3, then 4).

Concept 5: Decisions The If / Else Fork

FORK IN THE ROAD
Everyday Life: IF it is raining outside → put on raincoat. ELSE → wear a sun hat!

An If - Else block lets your robot ask a question. If the answer is YES (True), it takes the top road. If the answer is NO (False), it takes the bottom road.

if < question is YES > then → Turn Left | else → Turn Right (Takes this turn whenever the answer is NO!)
1 mod 2 = 1 (Odd step) → 1 leftover! Condition is FALSE → Wizbot takes else! 2 mod 2 = 0 (Even step) → 0 leftover! Condition is TRUE → Wizbot takes then! 3 mod 2 = 1 (Odd step) → 1 leftover! Wizbot switches back!

The Young Inventor's Challenge: Plan Your Own Zigzag!

Level / Mission Goal Your Coding Hint
Level 1: Easy
Classic Zigzag		 Make Wizbot walk forward and alternate between 90° left and right turns for 6 steps. Check your mod 2 = 0 condition and make sure your counter changes by 1 every loop!
