    + - * / % calculate; == != < <= > >= compare; && || ! combine conditions. += -= ++ -- update numbers. true and false are Boolean values. // starts a comment. Variables declared in a block stay in that block; use different names for nested loops.
    Robot commands
    forward(steps); reverse(steps); left(); right(); action();
    In Draw mode: turn(degrees); moveTo(x, y); (positive turn is clockwise; x is right and y is up from Start). moveTo travels along a straight segment; it never teleports. left45(); right45(); left30(); right30(); arcLeft(radius); arcRight(radius); wideLeft(); wideRight();
    Run limits
    10,000 execution steps, 200 printed lines and 200 movement commands. A limit stops the run and keeps the travelled path. Code paths auto-fit the board; the button builder retains its fixed edge. Stop code interrupts loops. Numbers must stay within ±1,000,000,000,000. Lengths and radii are 0–1000 step units, excluding zero. The default is one step. Turns accept −360° to 360°; coordinates accept −1000 to 1000. This is a teaching language, not a full JavaScript editor.

        Transparent scoring rules

        A route must match the ordered target travel, total distance (within 1.5% or 0.08 step), and final heading (within 5°). Up to 1,000 points: code = min(400, 400 × reference statements / your statements); bot = min(400, 400 × reference bot seconds / your bot seconds); coding = 200 / (1 + elapsed coding seconds / 120). Values are rounded.

        Code efficiency counts parsed statements, including loop headers and assignments; squeezing statements onto one line does not help. For example, repeat (4) { forward(input); reverse(input); right(); } counts as 4 logical statements: one repeat and three movement commands. Formatting those statements across multiple lines gives exactly the same score. Bot time includes distance ÷ speed, turns ÷ turning speed, a 1-second action delay, and heading alignment for coordinate moves. Arc travel uses arc length. Coding time runs from round start until each Run click, including earlier attempts. Speed settings stay locked for the round. Scores are local, editable practice results.
