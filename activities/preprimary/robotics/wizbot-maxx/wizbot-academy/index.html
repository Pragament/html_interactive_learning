Language and movement reference
Decisions
if (input % 2 == 0) { print("even"); } else { print("odd"); }
Loops
repeat (4) { forward(); right(); }
for (let i = 1; i <= 5; i++) { print(i); }
let n = 3; while (n > 0) { print(n); n--; }
Variables and operators
let total = 0; total = total + 1;
+ - * / % calculate; == != < <= > >= compare; && || ! combine conditions. += -= ++ -- update numbers. true and false are Boolean values. // starts a comment. Variables declared in a block stay in that block; use different names for nested loops.
Robot commands
forward(steps); reverse(steps); left(); right(); action();
In Draw mode: left45(); right45(); left30(); right30(); arcLeft(radius); arcRight(radius); wideLeft(); wideRight();
Run limits
10,000 execution steps, 200 printed lines and 200 movement commands. A limit stops the run and keeps the travelled path. Code paths auto-fit the board; the button builder retains its fixed edge. Stop code interrupts loops. Numbers must stay within ±1,000,000,000,000. Lengths and radii are 0–1000 step units, excluding zero. The default is one step. This is a teaching language, not a full JavaScript editor.
