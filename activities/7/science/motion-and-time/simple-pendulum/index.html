🔬 Simple Pendulum Lab

Class VII • Science • Motion and Time

Suspend a bob from a G-clamp, displace and release it, measure the time for 20 oscillations, and calculate the time period.

📋 Procedure

1. Suspend the pendulum bob from the G-clamp.
2. Set the pendulum length.
3. Displace the bob using the starting angle.
4. Click Release / Start.
5. Measure the time taken for 20 complete oscillations.
6. Calculate the time period: T = total time ÷ 20.

⚙️ Controls

Ready. Displace the bob and release it.

📐 Formula

T = t / 20
Theoretical: T = 2π√(L / g)

g = 9.8 m/s²
