How can we help?

Report a problem, suggest an improvement, or contribute a fix to the project.

1. Check whether it is already reported

Search both open and closed issues first. A closed issue may already contain a solution or explanation.

Browse all issues Open issues Closed issues

2. Create an issue if none exists

Describe what happened, what you expected, the activity involved, and steps that help someone reproduce the problem.

Create GitHub issue

3. Optionally fix it yourself

  1. Fork the repository and create a focused branch.
  2. Use your preferred editor or AI coding assistant to understand, implement, and test the fix.
  3. Push the branch and open a pull request explaining the change.
